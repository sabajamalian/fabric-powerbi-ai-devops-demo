## Big picture

This repo teaches agentic GitHub Copilot work with a Power BI Project. The semantic model is TMDL text. The report is PBIR JSON. The data is 100 percent synthetic retail pharmacy data for 12 stores, four regions, and dates from 2024-01-01 to 2025-12-31. No Fabric tenant is required.

Every agent customization is source controlled. Instructions, skills, custom agents, prompt files, hooks, MCP config, validation scripts, questions, expected answers, and lab checks are reviewable files.

Power BI Desktop is Windows-only. The Power BI Modeling MCP server can connect to the open Desktop model or inspect the PBIP folder. The source-controlled config pins the package version.

## GitHub loop

<Mermaid
  label="GitHub pull request and publishing loop"
  code={`flowchart LR
    Branch[Feature branch] --> PR[Pull request]
    PR --> CI[CI validate and site jobs]
    PR --> Review[Copilot code review]
    Issue[Scoped issue] --> Cloud[Copilot cloud agent]
    Cloud --> PR
    CI --> Merge[Merge to main]
    Merge --> Pages[GitHub Pages]
    Pages --> Site[Self-paced lab site]
  `}
/>

`ci.yml` has `validate`, `site`, and `dependency-review` jobs. `validate` runs on Ubuntu and Windows. `site` builds Astro Starlight. `dependency-review` runs only on pull requests.

## Data and evaluation flow

<Mermaid
  label="Data, model, and evaluation flow"
  code={`flowchart LR
    Gen[pharmacy_demo.datagen] --> CSV[data/generated CSVs]
    Gen --> Schema[data/schema/tables.json]
    CSV --> TMDL[Semantic model TMDL]
    TMDL --> PBIR[PBIR report]
    CSV --> Oracle[DuckDB oracle]
    Oracle --> Expected[evaluation/expected Q01 to Q05]
    TMDL --> Tester[question-tester agent]
    Tester --> Runs[evaluation/runs]
    Expected --> Grader[grader]
    Runs --> Grader
  `}
/>

The DuckDB oracle computes expected answers directly from CSV files. It does not trust the semantic model.

## Python package organization

| Module | Owns |
|---|---|
| `cli.py` | `python -m pharmacy_demo` commands wrapped by PowerShell scripts. |
| `datagen.py` | Deterministic synthetic data and schema generation. |
| `oracle.py` | DuckDB expected answers. |
| `evaluation.py` | Run schema validation, grading, and comparison. |
| `tmdl.py` | TMDL parser and linter. |
| `pbir.py` | PBIR report binding checks. |
| `conventions.py` | Rules C01 to C15 from `rules/*.yaml`. |
| `repo_checks.py` | Hygiene, identifier, secret, PHI-like, and prose checks. |
| `customizations.py` | Static checks for Copilot customization files. |
| `hooks.py` | Hook decisions and hook logging. |
| `labcheck/checks.py` | Lab progress checks from `lab/checks.yaml`. |
| `modelgen/*` | Maintainer-only checkpoint model generator. |
