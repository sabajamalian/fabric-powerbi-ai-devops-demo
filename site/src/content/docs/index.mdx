<Aside type="caution" title="Synthetic data only">
Every store, medication, and prescription fill in this lab is generated by a script with a fixed seed. There are no patients, no people, and no protected health information anywhere in the repo. Don't use this repo, or anything you build from it, for real health data.
</Aside>

## What you'll build

You start with a Power BI Project (PBIP) whose semantic model has cryptic names, no descriptions, a missing relationship, and no measures. In the committed sample runs, a Copilot agent asked five business questions about it scores 3 out of 10. After the improvements, the same questions score 10 out of 10. Your live runs will vary a little. Along the way, you build and use every kind of Copilot customization.

## What you need

- A GitHub account with a Copilot plan that includes agent mode and MCP. Labs 12 and 13 need Copilot code review and the Copilot cloud agent, which need a paid plan.
- Windows 11 for the full track, because Power BI Desktop runs only on Windows. macOS works for the customization-only track.
- About 10 GB of free disk space and permission to install PowerShell 7, Git, Python, Node.js, VS Code, and Power BI Desktop.
- No Microsoft Fabric tenant, capacity, workspace, or service principal. Nothing in this lab touches the cloud except GitHub.

See [Prerequisites](/start/prerequisites/) for the full list.
