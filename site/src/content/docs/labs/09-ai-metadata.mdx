## Why this matters

Copilot, Q&A, and Fabric data agents don't only read table names. They also need business rules that don't fit cleanly in a measure description. Prep data for AI gives you a place to define those rules, narrow the schema, add synonyms, and map verified answers to approved visuals. In this repo, the Power BI-managed files for those features are treated as preview output, so you draft the content as plain text first and apply it later in Power BI Desktop or the Power BI service.

## Concepts

- **Prep data for AI:** a Power BI authoring experience for AI instructions, AI data schemas, and verified answers. Microsoft Learn marks the experience as preview, and the exact Desktop and service UI can move between monthly releases.
- **AI instructions:** model-level business guidance. This is where you define latest month, previous period, refill thresholds, and processing time. See [AI readiness](/reference/ai-readiness-checklist/).
- **AI data schema:** the subset of model objects that AI tools should use for question answering. It reduces noisy choices.
- **Synonyms:** alternate phrases on tables, columns, and measures. In this lab they stay in `fabric/ai-prep/synonyms.yaml` until a person applies them in Power BI.
- **Verified answers:** reviewed answer candidates that map a business question to a visual and trigger phrases.

<Aside type="note" title="Preview disclaimer">
The Microsoft Learn article [Prepare Your Data for AI to Improve Copilot Results](https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-prepare-data-ai) says authors can now use **Prep data for AI** in both Power BI Desktop and the Power BI service. It is still labeled preview. These labs keep drafts in `fabric/ai-prep/` because preview file formats can change.
</Aside>

## Troubleshooting

<details>
<summary>The agent created a semantic model Copilot folder</summary>

Reject that change. Run `git restore -- fabric/ContosoPharmacy.SemanticModel/Copilot` if the folder exists, then rerun `/write-ai-prep-drafts` and remind the agent: "Draft only in fabric/ai-prep. Do not create or edit the Desktop-managed Copilot folder." The hook is designed to deny that edit in CLI and cloud agent, but VS Code agent behavior can vary by version.

</details>

<details>
<summary>The instructions check says a required term is missing</summary>

Open `fabric/ai-prep/ai-instructions.md` and add a short sentence for the missing concept. The check looks for the terms in `rules/required-model-objects.yaml`: December 2025, previous month, Refill Rate Index vs Chain, 1.25, Avg Processing Time (min), and Therapeutic Category.

</details>

<details>
<summary>The synonyms YAML doesn't parse</summary>

YAML treats colons and brackets as structure. Keep keys unquoted only when they match the examples. If you get a parse error, quote the key, for example `'Prescription Fill[Prescriptions Filled]'`, and rerun `pwsh ./scripts/lab/Test-LabProgress.ps1 -Lab 09`.

</details>

<details>
<summary>Power BI Desktop doesn't show Prep data for AI</summary>

The feature is preview and version dependent. Check **File > Options and settings > Options > Preview features**. If the option isn't there, keep the drafts in `fabric/ai-prep/` and apply them later in the Power BI service when your tenant has the feature.

</details>
