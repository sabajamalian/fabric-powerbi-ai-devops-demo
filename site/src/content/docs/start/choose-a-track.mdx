## Platform notes

Windows 11 with Power BI Desktop gives you the full lab. These labs need Desktop for the main path:

- [Lab 02](/labs/02-meet-the-baseline-model/) opens and refreshes the PBIP.
- [Lab 04](/labs/04-connect-mcp/) connects MCP to a Desktop model.
- [Lab 05](/labs/05-question-tester-before/) uses live metadata and DAX through MCP.
- [Lab 08](/labs/08-relationships-and-measures/) runs Desktop DAX tests.
- [Lab 10](/labs/10-question-tester-after/) repeats the live question test.

macOS can still do file-mode work with TMDL, PBIR, instructions, skills, prompts, hooks, validation, and most repo checks. Desktop-specific checks skip or need a Windows machine.

## Copilot plan notes

Most labs work with VS Code Chat and agent mode. The later GitHub-hosted features need more:

- [Lab 12](/labs/12-pull-request-and-code-review/) needs Copilot code review. GitHub documents code review as a Copilot feature that can also be controlled by organization policy.
- [Lab 13](/labs/13-cloud-agent/) needs Copilot cloud agent. Organization admins may need to enable it for Business or Enterprise seats.
- MCP, custom agents, prompt files, and Copilot CLI can also be disabled by organization policy, even when your account has a Copilot seat.

<Aside type="note" title="If a paid feature is blocked">
Use the Core track through Lab 11, or read the presenter fallback pages. The repo has sample outputs for baseline and AI-ready runs, so you can still see the learning arc.
</Aside>
