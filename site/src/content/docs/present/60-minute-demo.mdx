## Goal

Run the same story as the 30-minute demo, then add deterministic DAX tests, the Copilot cloud agent workflow, and a short build-your-own customization exercise.

## Have pre-run

- Everything from the [30-minute demo](/present/30-minute-demo/).
- Power BI Desktop open with the AI-ready checkpoint for Lab 08.
- A completed `Invoke-DaxQuestionTests.ps1` output.
- A cloud-agent issue and branch ready to show.
- A small Lab 14 customization idea prepared, such as a new prompt or skill reference.

## Timing table

| Time | Segment | Show | Transition sentence |

## Segment notes

### Setup

Say: "There is no hidden service dependency for the lab. The dataset, oracle, grader, model files, site, and checks are all in this repo."

### Lab 05 before run

Show a baseline run and the JSON shape. Keep the focus on repeatability.

Link: [Lab 05](/labs/05-question-tester-before/).

### Lab 06 assessor

Show the skill catalog and the `model-assessor` agent. Point out that the assessor can read model files and rules but should not make edits.

Link: [Lab 06](/labs/06-skills-and-assessor/).

### Lab 07 handoff

Show the handoff card or prompt from assessor to improver. Then show the actual changed TMDL names and descriptions.

Link: [Lab 07](/labs/07-handoffs-names-descriptions/).

### Lab 08 DAX tests

Run or show:

```powershell
pwsh ./scripts/Invoke-DaxQuestionTests.ps1
```

Say: "The natural-language evaluator tells us whether the assistant can answer. The DAX tests tell us whether the model can calculate."

Link: [Lab 08](/labs/08-relationships-and-measures/).

### Lab 10 comparison

Open [Expected results](/present/expected-results/) and the comparison output.

Say: "The expected answers came from DuckDB, not the semantic model, so a broken model cannot grade itself."

Link: [Lab 10](/labs/10-question-tester-after/).

### Lab 11 hooks

Show a denied protected edit, an ask decision for destructive cleanup, and a post-edit lint message if you have one.

Link: [Lab 11](/labs/11-copilot-cli-and-hooks/).

### Lab 12 PR

Open the PR. Show validation, template fields, CODEOWNERS, model-reviewer notes, and Copilot review.

Link: [Lab 12](/labs/12-pull-request-and-code-review/).

### Lab 13 cloud agent

Show `.github/workflows/copilot-setup-steps.yml`, the cloud issue, and the cloud agent branch or PR.

Say: "Cloud agent works best when the repo already has setup steps, tests, instructions, and tight issue scope."

Link: [Lab 13](/labs/13-cloud-agent/).

### Lab 14 in five minutes

Pick one small extension: a prompt, a skill reference, or a rule update. Do not build a full new lab live.

Say: "Build-your-own does not start with a giant agent. It starts with one repeated task and the smallest customization that makes it reliable."

Link: [Lab 14](/labs/14-build-your-own/).

<Aside type="tip" title="Use the 60-minute format for workshops">
The longer version gives learners time to see the difference between answer quality, model correctness, guardrails, and pull request governance.
</Aside>
