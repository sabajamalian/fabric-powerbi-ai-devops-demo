## Surface notes

### VS Code agent mode

VS Code is the richest local surface. It reads workspace instructions, `AGENTS.md`, custom agents, skills, hooks, and `.vscode/mcp.json`. Prompt files still work for the Local agent, but the docs say Agent Host does not load them.

Open **Chat: Open Customizations** from the Command Palette to inspect what VS Code found.

### Copilot CLI

Copilot CLI reads repository instructions, path instructions, `AGENTS.md`, repository custom agents, skills, hooks, and MCP config. The CLI MCP config location is `~/.copilot/mcp-config.json` by default.

### Copilot cloud agent

Cloud agent reads repository instructions, path instructions, `AGENTS.md`, and `.github/agents`. This repo prepares cloud sessions with `.github/workflows/copilot-setup-steps.yml`, which installs Python tools and the pinned Skills for Fabric skill.

### Copilot code review

GitHub docs confirm repository-wide instructions, path instructions, `AGENTS.md`, and agent skills for pull request review on GitHub.com. Docs also say review reads these from the head branch.

### github.com chat

Regular github.com chat supports repository-wide instructions when the repo is attached as context. The current support table does not list path instructions, `AGENTS.md`, skills, agents, prompts, hooks, or `.vscode/mcp.json` for regular chat.
