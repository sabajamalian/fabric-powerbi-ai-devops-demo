## Why this matters

You need a baseline before an improvement means anything. The `question-tester` agent acts like an analyst's AI assistant: it reads the model, writes DAX, records assumptions, and saves answers in a schema the grader can score. The baseline model is intentionally weak, so a low score is not failure. It's evidence you can compare after the model becomes AI-ready.

## Concepts

- **Custom agent:** a `.github/agents/*.agent.md` file that defines an agent's purpose, tools, boundaries, and handoffs. See [Agents](/reference/agents/#question-tester).
- **Prompt file:** a reusable chat task. `/answer-business-questions` passes a `label` input to the agent and tells it where to save the run. See [Prompts](/reference/prompts/).
- **Evaluation run:** `evaluation/runs/<label>.json`, with one answer object per question and a `grade` block written by the grader.
- **Expected-answer isolation:** the agent is told not to read expected answers, and the hook denies those reads for CLI and cloud-agent surfaces.
- **Grader:** `scripts/Grade-QuestionRun.ps1` scores each answer 0, 1, or 2 against the deterministic expected answers.

### Step 4. Run the prompt with the local-baseline label

1. Open Copilot Chat: **Ctrl+Alt+I** (macOS: **Ctrl+Cmd+I**), or **View > Chat**.
2. Switch to **Agent** mode.
3. Pick **question-tester** from the agent dropdown.
4. Type this prompt and press **Enter**:

```text

```

VS Code prompt files can also show an input box for `label`. This prompt declares the input as `${input:label:local-baseline or local-ai-ready}`:

<RepoFile path=".github/prompts/answer-business-questions.prompt.md" />

**You should see:** the agent calls `Get-BusinessQuestions.ps1`, connects through Power BI Modeling MCP, runs one DAX query per question, and writes `evaluation/runs/local-baseline.json`. It then runs `Grade-QuestionRun.ps1 -Run local-baseline`.

## Troubleshooting

<details>
<summary>The question-tester agent is missing from the picker</summary>

Run **Developer: Reload Window** from **View > Command Palette**. If it still does not appear, open `.github/agents/question-tester.agent.md` and check for frontmatter errors. VS Code usually reports custom-agent parse errors in **View > Output**, then the **GitHub Copilot Chat** channel.

</details>

<details>
<summary>The prompt asks me for a label even though I typed one inline</summary>

Use `local-baseline` in the input box and continue. VS Code prompt input handling can vary by version. The prompt file's label input still resolves to the same run path.

</details>

<details>
<summary>The run file fails schema validation</summary>

Check that the top-level fields include `label`, `model_state`, `created`, and `answers`. Each answer needs `question_id` and `rows`. Do not hand-write the `grade` block. Run `pwsh ./scripts/Grade-QuestionRun.ps1 -Run local-baseline` after the shape is valid.

</details>

<details>
<summary>The agent tries to read evaluation/questions.yaml or expected answers</summary>

Stop the run and remind it: "Use only `pwsh ./scripts/Get-BusinessQuestions.ps1` for the questions. Do not read expected answers." In VS Code this is an instruction violation. In CLI and cloud-agent runs, the hook denies it.

</details>

<details>
<summary>DAX tool calls fail or return no rows</summary>

Go back to [Lab 04](/labs/04-connect-mcp/). Power BI Desktop must have `fabric\ContosoPharmacy.pbip` open and refreshed, the MCP server must be running, and the Power BI tools must be selected in **Configure Tools**.

</details>
