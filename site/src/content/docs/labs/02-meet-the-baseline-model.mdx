## Why this matters

The baseline model is valid, but it is not friendly to people or AI tools. It uses source-system names, has weak relationships, leaves keys visible, and gives agents almost no definitions. You inspect those defects before asking Copilot to fix them later. Seeing the problems in both Desktop and text makes the rest of the lab feel concrete.

## Concepts

- **PBIP:** a Power BI Project saved as files so Git and agents can review changes. See [Architecture](/reference/architecture/).
- **TMDL:** the text format for the semantic model under `fabric/ContosoPharmacy.SemanticModel/definition/`.
- **PBIR:** the report format under `fabric/ContosoPharmacy.Report/definition/`, with one `visual.json` per visual.
- **Relationship:** the TMDL link between model tables. Missing or bidirectional relationships can make answers wrong.
- **DataFolderPath:** the Power Query parameter that points Desktop at the synthetic CSV folder.

## Before you begin

- Finish [Lab 01](/labs/01-get-your-copy/).
- On Windows, Power BI Desktop is installed.
- Close other Power BI Desktop files so you know which model the later checks find.

<PlatformBadge kind="windows-only" />

### Step 2. Read how the model finds data

Open `fabric/ContosoPharmacy.SemanticModel/definition/expressions.tmdl` in VS Code:

- Keyboard: **Ctrl+P** (macOS: **Cmd+P**), type the file name, press **Enter**.
- Command Palette: **Ctrl+Shift+P** (macOS: **Cmd+Shift+P**), run **File: Open File**, then pick the file.

**You should see:** `DataFolderPath` defaults to `C:\ContosoPharmacyDemo\data\` and is marked as a required text parameter.

<PlatformBadge kind="windows-only" />

### Step 4. Find the baseline defects in the model

In Desktop Model view, look for these issues. Then match each one to a repo file.

1. Tables and columns use source names such as `fact_rx_fill`, `dim_store`, `rgn`, and `proc_mins`.
2. `fact_rx_fill` has a relationship to Date and Store, but not to Medication.
3. The Store relationship is bidirectional.
4. Auto date/time is enabled.
5. Numeric keys and helper columns summarize by sum.
6. There are no descriptions or measures.

The text files show the same defects:

<RepoFile path="fabric/ContosoPharmacy.SemanticModel/definition/model.tmdl" lines="9-14" />

<RepoFile path="fabric/ContosoPharmacy.SemanticModel/definition/relationships.tmdl" />

<RepoFile path="fabric/ContosoPharmacy.SemanticModel/definition/tables/fact_rx_fill.tmdl" lines="1-78" />

**You should see:** the missing Medication relationship, `crossFilteringBehavior: bothDirections`, `annotation __PBI_TimeIntelligenceEnabled = 1`, raw source names, and sum summarization on IDs and keys.

<Checkpoint lab="02" step="6" />

### Step 7. Write down five defects

Create a short note outside the repo, or use a scratch note in your editor that you don't save into the repository. Capture at least five defects you saw. Use this list later when the model-assessor runs in [Lab 06](/labs/06-skills-and-assessor/).

A good list includes:

- Raw table and column names.
- No descriptions.
- Missing relationship to Medication.
- Bidirectional Store relationship.
- Auto date/time enabled.
- Keys visible or summarized.
- Processing minutes summed in the report.

**You should see:** your own defect list. You don't need to commit anything.

## Troubleshooting

<details>
<summary>Refresh says the folder or CSV files can't be found</summary>

Run `pwsh ./scripts/Set-LocalDataLink.ps1` again and confirm it links `C:\ContosoPharmacyDemo\data` to this clone's `data\generated`. If you changed the model parameter, use **Home > Transform data > Edit parameters** and set it back.

</details>

<details>
<summary>Power BI Desktop asks about privacy levels</summary>

Choose settings that let Desktop read local files from your machine. The data is synthetic and local. Don't sign in to a Fabric workspace or publish anything for this lab.

</details>

<details>
<summary>Desktop rewrote files under `fabric/`</summary>

Close Desktop. If you only inspected the model, run `git restore fabric` to discard the rewrite. Later labs tell you when to keep Desktop-generated changes.

</details>

<details>
<summary>The model opens as a single model file instead of TMDL</summary>

Check **File > Options and settings > Options > Preview features** and enable the PBIP and TMDL options if they appear. Restart Desktop and open `fabric\ContosoPharmacy.pbip` again.

</details>

<details>
<summary>On macOS, the Desktop check skips or fails</summary>

That's expected. Power BI Desktop is Windows only. The file-mode checks still let you read the model and continue with labs that don't need Desktop.

</details>
