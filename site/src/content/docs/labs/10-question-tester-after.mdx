## Why this matters

You improved names, relationships, measures, and AI metadata. Now you measure whether those changes helped. The question-tester agent answers the same five questions from Lab 05, writes another run file, and lets the grader score it the same way. This is still an agent run, so wording and sometimes a point can vary, but the AI-ready model should score clearly higher than the baseline.

## Concepts

- **After run:** a second graded question run against the AI-ready model. The label in this lab is `local-ai-ready`.
- **Rubric:** deterministic scoring against expected rows. It checks answer data, not explanation style. See [Evaluation methodology](/reference/evaluation-methodology/).
- **Run variance:** agent answers can differ between runs. The comparison is useful because the same grader and same questions are used before and after.
- **Deterministic DAX tests:** the Lab 08 DAX tests exist because agent runs vary. They run fixed DAX queries against Desktop and don't rely on agent judgment.

### Step 5. Account for run variance

Run variance is expected because the agent chooses DAX and interpretations. Don't overreact to a one-point wobble.

1. Ask question-tester: `Explain any question in local-ai-ready that scored below 2. Point to the model change that would help.`
2. If one score looks surprising, run the after test a second time with a different local label.

<Tabs syncKey="os">
<TabItem label="Windows">

```powershell
# Optional second run. The prompt supports labels, not a paraphrase flag.
# In chat: /answer-business-questions label=local-ai-ready-2
pwsh ./scripts/Grade-QuestionRun.ps1 -Run local-ai-ready-2
pwsh ./scripts/Compare-QuestionRuns.ps1 -Before local-ai-ready -After local-ai-ready-2 -OutFile out/question-variance.md
```

</TabItem>
</Tabs>

**You should see:** two AI-ready runs that are close. If they differ, the assumptions field usually explains why. The deterministic proof still comes from the Lab 08 DAX tests, not from repeated agent runs.

## Troubleshooting

<details>
<summary>The agent says Desktop or MCP isn't available</summary>

Open `fabric\ContosoPharmacy.pbip` in Power BI Desktop, refresh it, and start the Power BI Modeling MCP server from **Ctrl+Shift+P > MCP: List Servers**. Then rerun `/answer-business-questions label=local-ai-ready`.

</details>

<details>
<summary>The run file has no grade block</summary>

Run `pwsh ./scripts/Grade-QuestionRun.ps1 -Run local-ai-ready`. The evaluation instructions say the grader writes the `grade` block, not the agent by hand.

</details>

<details>
<summary>The comparison says AI-ready did not improve</summary>

Open both run files and check labels first. If the labels are right, read each failed question's assumptions. A wrong latest month, summed processing minutes, or missing refill threshold means the agent didn't use the AI-ready metadata. Ask it to answer again and cite the measure or instruction it used.

</details>

<details>
<summary>I want to test paraphrases</summary>

Each question in `evaluation/questions.yaml` lists paraphrases (see [Business questions](/reference/business-questions/)). Ask the question-tester one of them in chat, for example "Which categories grew or shrank the most last month?", and compare its DAX with the graded run. The grader and the Lab 10 check only score the main wording, so treat this as exploration.

</details>
