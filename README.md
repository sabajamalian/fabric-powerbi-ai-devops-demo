# Contoso Pharmacy Copilot Lab

A hands-on lab for GitHub Copilot agent customization, built around a Power BI semantic model stored as code. You start with a weak model (cryptic names, no descriptions, a missing relationship, no measures) that a Copilot agent answers five business questions about and scores 3 out of 10. Using repository instructions, skills, custom agents with handoffs, prompt files, hooks, Power BI Modeling MCP, and APM, you turn it into a model that scores 10 out of 10, then take the change through a pull request, CI, Copilot code review, and the Copilot cloud agent.

**Start here: [the self-paced lab site](https://sabajamalian.github.io/fabric-powerbi-ai-devops-demo/).** It has 16 labs, four tracks (from 1.5 hours to a full day), a verify command for every lab, and presenter scripts for 30 and 60 minute demos.

> [!CAUTION]
> **Synthetic data only.** Every store, medication, and prescription fill is generated by a script with a fixed seed. There are no patients, no people, and no protected health information in this repo. Don't use it, or anything built from it, with real health data. See [SECURITY.md](SECURITY.md).

## What's in the repo

| Folder | What it holds |
|---|---|
| `fabric/` | The Power BI Project (PBIP): the semantic model as TMDL and the report as PBIR |
| `.github/` | Copilot instructions, path instructions, skills, custom agents, prompt files, hooks, workflows, and issue forms |
| `AGENTS.md` | Instructions for any coding agent working in the repo |
| `.vscode/` | Recommended extensions, settings, tasks, and the MCP server config (no secrets) |
| `data/` | The synthetic dataset (CSV) and its schema |
| `evaluation/` | Five business questions, their expected answers, the grading rubric, and sample runs |
| `rules/` | Model conventions (C01 to C15) that the lint and the assessor agent check |
| `lab/` | The lab verification contract and checkpoint list |
| `scripts/` | PowerShell 7 entry points for setup, validation, grading, hooks, and lab checks |
| `tools/python/` | The `pharmacy_demo` package behind the scripts (data generator, TMDL lint, grader, lab checks) |
| `site/` | The lab site (Astro Starlight), published to GitHub Pages |

## Quick start

Windows 11 with PowerShell 7 is the primary platform. Power BI Desktop runs only on Windows, so on macOS you can do the Copilot customization labs but not the Desktop steps. No Microsoft Fabric tenant, capacity, or workspace is needed.

1. Click **Use this template** on GitHub and create your own copy, then clone it.
2. Check your tools. The script only checks; it installs nothing.

   ```powershell
   pwsh ./scripts/Test-Prerequisites.ps1
   ```

3. Create the Python environment and run validation:

   ```powershell
   pwsh ./scripts/Initialize-DevEnvironment.ps1
   pwsh ./scripts/Invoke-Validation.ps1
   ```

4. Open the folder in VS Code, install the recommended extensions, and follow [Lab 00](https://sabajamalian.github.io/fabric-powerbi-ai-devops-demo/labs/00-workstation-setup/) on the site.

To read the site offline or preview edits, run `pwsh ./scripts/lab/Start-LabSite.ps1` (needs Node.js 20 or later).

## Status

Everything in the repo runs in CI on Ubuntu and Windows without a Fabric tenant. The labs haven't been run end to end on a clean Windows 11 machine yet, and several of the tools they use are in preview. See [Known limitations](https://sabajamalian.github.io/fabric-powerbi-ai-devops-demo/help/known-limitations/) and please [report anything that doesn't match](https://github.com/sabajamalian/fabric-powerbi-ai-devops-demo/issues/new?template=lab-feedback.yml).
